# Campeonato do Bairro — отчёт

Нативное бесплатное приложение iPhone + iPad, iOS 17.4+, версия 1.3.7 (143). Хеши ТЗ и README проверены. Другие проекты и исходники фабрики не изменялись.

Реализованы круговые турниры и олимпийские сетки на 2–32 команды, проходы без игры, расписание, протоколы, пенальти, таблицы, статистика голов, составы и голосование за игроков завершённого тура. Исправление победителя сбрасывает зависимые результаты. Есть PDF-дипломы, локальное сохранение и восстановительная копия при повреждённом архиве. Пример явно помечен во всех вкладках и исключён из виджетов, синхронизации и напоминаний.

CloudKit использует приватные приглашения, проверку протоколов владельцем, объединение изменений, защиту от устаревших протоколов, смены аккаунта и восстановления удалённых зон. Профиль Sign in with Apple необязателен. Напоминания локальные, старые задачи отменяются при изменении данных. Удаление профиля очищает свои локальные данные, временные дипломы, резервные копии и уведомления; свои облачные турниры удаляются, из чужих выполняется выход. Чужой владелец сохраняет результаты — это объяснено в приватности.

Виджеты small/medium/large и три формата Lock Screen работают из App Group без сети. Большой виджет содержит мини-сетку, топ-6 и календарь тура. Live Activity не используется по индивидуальному ТЗ. EN, PT-BR, ES, DE, FR, IT: 181 строка, InfoPlist-каталог, ASO и описания. Иконка оригинальная.

## Файлы

- Проект: `Riacho.xcodeproj`, схема `Riacho`.
- Один app-таргет, обязательный WidgetKit extension и тестовый таргет; шесть Swift-файлов, без сторонних зависимостей.
- Bundle `com.campeonatodobairro.app`, App Group `group.org.courtyard.mosaicr7`, CloudKit `iCloud.org.courtyard.mosaicr7`.
- `Delivery/Riacho-source.zip` — исходники; `Delivery/Riacho-unsigned-iphoneos.zip` — неподписанная сборка; `Delivery/SHA256.json` — контрольные суммы.
- `Evidence/` — QA, снимки, результаты и сохранённые данные. `Build/` — отдельные сборки и DerivedData, исключённые из исходников.
- `Metadata/` — приватность, локали стора, решения по Apple SDK и первичные источники.

## Оставшиеся ограничения

Публикации и платных действий не было. Реальным CloudKit/Apple sign-in нужны команда разработчика, provisioning и развёрнутая схема CloudKit. Два настоящих iCloud-аккаунта здесь не проверены. Редакторы — доверенные соорганизаторы: права CloudKit относятся ко всей записи, локальный блок не заменяет отзыв приглашения. При сетевой ошибке удаление облачных данных нужно повторить. Apple sign-in дополнительно отзывается в настройках устройства; серверный секрет и refresh token не хранятся.

Перед отправкой в стор нужны реальный контакт поддержки и опубликованный URL политики приватности. Текст подготовлен, вымышленные контакты не добавлялись. Галерея установленных виджетов отдельно не проверена. Все simulator-команды выполняются через обязательный `simulator_pool.py`; существующие устройства не стираются.
